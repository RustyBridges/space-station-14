# Derelict

A co-op salvage game mode for up to four players, built on Space Station 14
(RobustToolbox engine). A crew flies a tug between abandoned stations, hauls
back whatever sells, and has to meet a rising quota every three drops.

## Running it

Requires the .NET 10 SDK.

    git submodule update --init --recursive
    ./runserver-derelict.sh        # runserver-derelict.bat on Windows
    ./runclient.sh                 # connect to localhost

Everyone readies up in the lobby; all players spawn as Salvagers on the tug.

## How a run goes

1. **Deep space.** On the bridge, right-click the *navigation uplink* and pick
   one of three offered derelicts. Examine the uplink at any time for quota,
   drops left and the site clock.
2. **On site.** The tug docks (or parks next to the derelict). A clock runs:
   more threats wake up over time, the derelict's power fails at half time,
   its hull starts breaking up at three quarters, and at zero the autopilot
   leaves with whoever is aboard. *Depart now* on the uplink leaves early.
3. **Back in deep space.** Put salvage on the selling pallets in the main
   corridor and sell it at the pallet console on the bridge. Buy gear at the
   cargo console; crates arrive on the buying pallets.
4. After three drops the quota is due: submit it at the uplink. Met: a new,
   higher quota. Missed: the contract is terminated and the round ends.

Each site hides a **flight recorder** worth a large bonus.

**Death.** Carry a body back to the tug and revive it in the med bay
(defibrillator, cloner). Crew who were left behind, or are still dead when the
next drop launches, are replaced by a fresh clone for a fee.

## Threats

| Threat | Rule |
| --- | --- |
| Weathered statue | Only moves while no living crew member is facing it with a clear line of sight. |
| Eyeless thing | Blind. Goes to where it heard running or talking. Walk and whisper. Do not touch it. |
| Straggler | Only attacks crew with no living crewmate within five tiles. Backs off from groups. |

None of them can be killed.

## Where things are

| Path | What |
| --- | --- |
| `Content.Server/_Derelict/` | Run rule (drops, clock, quota), navigation console, admin command, threat AI |
| `Content.Shared/_Derelict/` | `derelictSite` prototype |
| `Resources/Prototypes/_Derelict/` | Preset, sites, job, threats, tuning values |
| `Resources/Maps/_Derelict/crew_ship.yml` | The tug. Generated by `Tools/derelict_make_ship.py` from the stock Dart shuttle |
| `Resources/ConfigPresets/derelict.toml` | Server settings |
| `Resources/Locale/en-US/_derelict/` | All text |

Sites currently reuse SS14's handcrafted ruin maps. To add one, map a grid,
save it, and add a `derelictSite` entry to `Resources/Prototypes/_Derelict/game.yml`.

## Admin command

`derelict status | sites | threats | launch <siteId> | depart | submit | skiptime <seconds>`
